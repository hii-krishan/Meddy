# Meddy — Find Your Softer Pace

A mindful web application rewritten in React, TypeScript, and Tailwind CSS. Meddy provides a calming sanctuary for busy minds with ambient music soundscapes, step-by-step yoga postures, inspiring stories, wellness reads, wise quotes, and interactive box breathing exercises.

## Features

- **Mood Check-in & Ritual Generator**: Check in with how you feel (Overwhelmed, Low Energy, Need Focus, Ready for Sleep, Anxious Mind, Seeking Stillness) and receive a personalized pause ritual with countdown timer.
- **Ambient Music Player**: 12 curated tracks with audio playback dock, progress scrubber, volume control, and category filters.
- **Foundational Yoga Postures**: 8 essential poses (Downward Dog, Tree Pose, Child’s Pose, Warrior II, Cobra Pose, Bridge Pose, Mountain Pose, Cat-Cow Flow) with Sanskrit naming, benefits, and step-by-step guides with practice hold timer.
- **Mindful Stories Carousel**: Thought-provoking narratives with wisdom reflection prompts.
- **Mindful Reads & Articles**: 6 evidence-backed articles on meditation, daily mindfulness, anxiety relief, yoga for mental health, self-care, and contentment.
- **Guided Breathing Sanctuary**: Interactive box breathing visualizer with real-time expansion animations, cycle counters, chime tones, and pattern presets (Box 4-4-4-4, 4-7-8 Relaxing, Gentle Flow 5-2-6-2).
- **Sage Speaker Quotes**: Inspiring words from teachers and philosophers with one-click copy and theme filters.
- **Responsive Design**: Centralized responsive framing optimized for both Windows desktop monitors and mobile smartphone displays.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 7 with `@vitejs/plugin-react-swc`
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Audio**: Web Audio API & HTML5 Audio

## Running Locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
